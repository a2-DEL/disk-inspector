# 📋 磁盘文件检视工具

> **只读扫描 + 风险分析 + 受控批量处理** —— 面向电脑小白的 Windows 本地磁盘治理工具。
> 不自动删除任何文件，所有修改操作必须手动勾选确认；系统高危文件硬锁定，操作全量留痕可还原。

## 🎯 它解决什么问题

C 盘爆红、电脑越用越慢，是几乎每个 Windows 用户都会遇到的困境。但市面上的工具要么**只告诉你"谁占了空间"却不告诉你"能不能删"**，要么**打着"一键清理"的旗号黑盒操作、误删风险极高**。

| 真实痛点 | 传统工具的做法 | 本工具的做法 |
|---|---|---|
| 看到 `WinSxS`、`.dll`、`pnpm-cache` 一堆看不懂的名字，不敢删 | 只给大小和方块图，自己猜 | **规则库自动翻译用途**，用大白话说明"这是什么、删了会怎样" |
| 怕删错导致系统崩溃、软件打不开 | 无差别可勾选，删错自负 | **白名单硬锁定**，系统核心目录勾选框直接禁用，选都选不了 |
| "一键清理"不知道它动了什么 | 黑盒静默删除，无记录 | **默认一个都不删**，必须手动勾选 + 清单预览 + 二次确认，全程写日志 |
| C 盘满了想搬到 D 盘，怕搬完软件用不了 | 不支持或粗暴剪切 | **受控迁移**：复制→校验→可选删除原文件，软件依赖文件禁止迁移 |
| 深度扫描大文件时程序突然闪退 | 递归遍历栈溢出、主线程阻塞 | **显式栈迭代 + 后台线程 + 全局异常兜底**，百万文件不崩溃 |

## ✨ 核心功能

### 🔍 双模式扫描
- **极速扫描**：只扫大文件、临时目录、卸载残留，跳过系统核心目录，几分钟出结果
- **深度全盘扫描**：遍历 C/D 盘全部目录，完整采集所有文件属性
- **实时控制**：暂停 / 继续 / 终止，实时显示当前目录、已扫描数量、已耗时、预计剩余时间
- **可选项**：是否显示隐藏文件、是否显示系统受保护文件（开启后仅展示、锁定不可勾选）、大文件阈值自定义（50MB / 100MB / 500MB / 1GB / 自定义）

### 🧠 智能分类与风险分级
基于可维护的 JSON 规则库，对每个文件/文件夹自动标注 **14 项属性**：

| 属性 | 说明 |
|---|---|
| 名称与类型 | 文件夹 / 后缀名（txt、exe、dll、mp4 等） |
| 具体用途 | 规则库匹配自动生成（浏览器缓存、安装包、系统驱动、用户照片…） |
| 是否系统/软件必需 | 是 / 否 / 不确定 |
| 能否安全删除 | 可删 / 谨慎 / 禁止 |
| 能否迁移 | 可迁移 / 不可迁移（软件依赖 dll 不可迁移） |
| 是否安装/卸载残留 | 是 / 否 |
| 是否大型文件 | 是（大于阈值，附大小）/ 否 |
| 创建时间 | 文件创建时间 |
| 文件体积 | B/KB/MB/GB 自动换算，排序按真实字节 |
| 文件大类 | 系统文件 / 应用软件文件 / 用户个人文件 / 临时缓存文件 / 空文件夹 |
| 风险等级 | 🔴高危 🟡中危 🟢低危 ⚪普通 |
| 处理建议 | 自然语言建议，文件作用讲明白，小白不理解技术术语也能看懂 |
| 占用状态 | 扫描阶段检测是否被进程占用，占用文件标记并禁止操作 |
| 重复文件 | 可选开启，按 SHA-1 哈希比对 |

### 📊 交互式 HTML 报告（离线单文件）
- **头部看板**：扫描摘要、总文件数、风险分类环形图、文件大类占比图
- **工具栏**：全局搜索、多条件筛选（风险/大类/大小）、表头点击排序
- **树形目录**：可折叠展开，与软件界面结构一致
- **批量勾选**：全选可操作 / 反选 / 清空，实时统计已选数量与总容量
- **高危行标红锁定**：复选框禁用
- **导出**：勾选清单 JSON（供工具导入执行）+ CSV 备份
- **纯离线**：不联网、不上传任何数据；浏览器安全限制下文件操作必须回到工具执行

### 🛠️ 受控批量操作（仅对勾选条目生效）
| 操作 | 说明 |
|---|---|
| **安全删除** | 两个选项：【移入回收站（默认推荐）】/【彻底删除（二次强确认，先移入工具安全回收箱可还原）】 |
| **批量备份** | 选择备份目录，自动按时间新建子文件夹，保留原始目录结构 |
| **批量迁移** | 选择目标磁盘目录，复制文件到目标；原文件可选择保留 / 删除；软件依赖文件禁止迁移 |
| **操作前预览** | 弹出清单预览，展示选中文件总大小 |
| **操作日志** | 实时记录，失败自动记录原因（文件占用、权限不足），可导出 |
| **安全回收箱** | 彻底删除的文件先移入工具内部回收箱，操作历史可一键还原 |

- 5 个页面：首页欢迎 / 扫描进度 / 结果预览 / 批量操作 / 设置

## 🛡️ 安全设计（核心竞争力）

### 三重保护，杜绝误删
1. **白名单硬锁定**：`System32`、`SysWOW64`、`WinSxS`、`WindowsApps`、`Boot`、`Recovery` 等系统核心目录下所有文件标记 🔴高危，**勾选框物理禁用，无法选中执行删除/迁移**
2. **占用检测**：扫描阶段检测文件是否被进程占用，占用文件标记并禁止加入操作队列
3. **操作前确认**：任何批量操作执行前弹出清单预览，展示选中文件总大小；删除动作二次确认弹窗，彻底删除额外警告

### 操作可追溯、可还原
- 所有操作写入 `%APPDATA%/DiskInspector/operations.log`，记录时间、操作类型、文件路径、成功/失败状态及原因
- "彻底删除"并非真正不可恢复——先移入工具内部**安全回收箱**，可在操作历史中一键还原；只有清空回收箱后才不可恢复
- HTML 报告不联网、不上传数据；网页受浏览器安全限制，文件操作必须回到本工具执行

### 安全模型与传统工具相反
传统清理工具默认"帮你清"，本工具默认**"一个都不碰"**——选择权和知情权完全交还给用户。

## ⚡ 性能与稳定性（深度扫描不崩溃的技术保障）

针对"深度扫描过程中程序意外自行关闭"的稳定性缺陷，已完成系统性修复并重新打包：

| 根因 | 修复方案 |
|---|---|
| PyQt6 槽函数未捕获异常会直接 `abort()` 静默退出进程（复现退出码 0xC0000409） | 安装全局 `sys.excepthook`：异常写入 `error.log` 并弹窗提示，程序不退出；关键槽函数加保护 |
| 扫描遍历用 Python 递归，超深目录树（数千层）下有 C 栈溢出 / 卡死风险 | 目录遍历改为**显式栈迭代**，任意深度不占用调用栈，不设递归上限 |
| 主线程同步执行「建索引 + HTML 导出」，数百万条目时内存峰值可致崩溃 | `build_index` 移入扫描线程；HTML 报告改为**后台线程 + 流式分块写入**，不再一次性构造超大 JSON 字符串 |
| 每个条目独占 `__dict__`，全盘扫描内存开销大 | `FileEntry` 改用 `__slots__`，显著降低单条内存占用 |
| 关闭窗口时扫描线程仍在运行，存在析构竞态 | `closeEvent` 先停止并等待扫描/导出线程再退出 |
| 超长路径下分类器对路径段做 O(段数×规则数) 成员遍历 | 关键词集合化 + 路径段一次性建 set，语义不变、速度大幅提升 |

**验证结果**：2 万文件端到端（扫描→建索引→结果页→后台导出）通过；12000 层超深目录从"卡死/崩溃"变为稳定完成；集成测试与 GUI 冒烟测试全绿；打包产物自检 `SELFTEST_OK`。

## 📖 使用流程（小白版）

1. **启动**：双击 EXE，UAC 提示选「是」（扫描系统目录需要管理员权限）
2. **扫描**：首页点「⚡ 极速扫描」（几分钟）或「🔍 深度全盘扫描」（最全，较慢）
3. **查看**：扫描完自动进入结果页——左侧选文件夹、右侧看明细；点表头排序、搜索/筛选
4. **勾选**：勾选想处理的条目（🔴红色高危行无法勾选，占用文件也无法勾选）
5. **操作**：到「批量操作」页——推荐先「备份」，再「安全删除 → 移入回收站」
6. **报告**：点「导出 HTML 报告」→ 浏览器打开 → 勾选 → 「导出勾选清单」→ 回工具「导入勾选清单」执行

## ⚙️ 自定义规则库

判定规则全部在 `config/rules.json`，可自行编辑维护：
- `whitelist`：系统核心目录（锁定不可操作）
- `cache_exts` / `installer_exts` / `system_critical_exts`：扩展名分类
- `residue_names`：卸载残留关键词
- `advice_templates`：处理建议文案模板

规则加载优先级：EXE 旁 `rules.json` → `%APPDATA%/DiskInspector/rules.json` → 内置打包资源 → 兜底默认。

## ❓ 常见问题

- **删除失败？** 多为文件被占用或权限不足，原因已记入日志，可查看「操作历史」。
- **报告打不开？** 用 Chrome / Edge 双击 HTML 即可，完全离线。
- **想改判定规则？** 编辑 `config/rules.json`（打包版在安装目录旁，或复制到 `%APPDATA%/DiskInspector/`）。
- **扫描很慢？** 深度全盘扫描会遍历所有目录，海量小文件（如开发缓存）耗时较长属正常；可先用极速扫描定位大文件和垃圾。
